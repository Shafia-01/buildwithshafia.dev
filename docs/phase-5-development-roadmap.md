# Important Portfolio Principle

Every development decision should answer:

> Does this help a recruiter understand who Shafia is within 30 seconds?

If not:

* remove it
* simplify it
* postpone it

This is why:

❌ Blog removed from V1

❌ Ask Shafia AI removed from V1

and

✅ Learnify AI receives flagship treatment

✅ KeyLytics showcases Agentic AI

✅ Demo videos become first-class proof of work

✅ Public resume protects privacy

The result should be a premium, recruiter-focused portfolio that faithfully implements the exact strategy, wireframes, UX flows, design language, and architecture already established in Emergent Phases 1–4 without altering them.
